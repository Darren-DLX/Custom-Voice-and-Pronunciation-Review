Question 1 · Custom Voice Support

How versatile is the custom voice across different performance styles?

Evaluate whether each custom voice can convincingly perform the styles required for the selected service. Test only performance styles applicable to the job: Lip Sync may require more extreme performances such as yelling, while Audio Description generally will not. Include whispering, moderate emotion, extreme emotion or other delivery styles only when they are relevant to that service. Select Not Applicable when appropriate.

Question 5 · Pronunciation

Can it pronounce this word correctly without any modification?

Regenerate each word at least 5–10 times before selecting one answer. Rate the overall pattern across those attempts, not a single generation.

6
Question 6 · Pronunciation

If it wasn't correct 100% of the time, did an alternate spelling, recording function or IPA help?

Test each relevant adjustment and regenerate the word at least 5–10 times after the change. Select every method that helped. For each word, you must enter both the number of attempts and the time needed before the pronunciation was acceptable. Include only the time spent getting the pronunciation right, not the total job time.

7
Question 7 · Pronunciation

If a given spelling change produces the desired result, can it be applied to other instances?

Select whether the successful spelling change also works in other sentences, with different voices, or under different emotional deliveries.

8
Question 8 · Pronunciation

If some sort of post-edit alternative worked, was it consistent?

Use the successful adjustment for at least 5–10 regenerations, then select the option that best describes its consistency.

Question 9 · Pronunciation

Please add any notes or comments associated with this word's pronunciation, if needed.

After completing at least 5–10 regenerations, record any recurring errors, useful spellings, IPA changes or other observations. Notes are optional.
